# Nexar

A project management dashboard built with React, TypeScript, Tailwind CSS, Vite, and Lucide React icons.

![Stack](https://img.shields.io/badge/React-18-61dafb) ![Stack](https://img.shields.io/badge/TypeScript-5-3178c6) ![Stack](https://img.shields.io/badge/Tailwind-3-38bdf8) ![Stack](https://img.shields.io/badge/Vite-5-a855f7)

## Features

- Fullscreen looping video background
- White pill-shaped header with Solo/Crew toggle
- Responsive 3-column grid layout (stacks on mobile)
- Reusable `TaskCard` component with colored tags and action buttons
- Sprint metrics card, productivity score, fast commands list
- Voice input card with waveform visualization
- Staggered fade-up entrance animations
- Instrument Serif display font

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
